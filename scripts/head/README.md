# Jarvis head model

`LeePerrySmith.glb` is the head scan of Lee Perry-Smith by Infinite-Realities (ir-ltd.net), licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). This copy comes from the three.js examples. If you publish the app, keep this credit, for example on an "About" screen.

To regenerate the files the avatars load, run `node scripts/head/export-head.mjs`. To use a different head, replace the `.glb`, then update the landmarks and the `CENTER` / `SCALE` values in the script.
